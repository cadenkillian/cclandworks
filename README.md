# C&C Landworks Website

This is the starter website for C&C Landworks.

## Before launch
1. Replace `YOUR-EMAIL-HERE` in `index.html` with the business email used for quote requests.
2. Add Caden's phone number and Chaz's phone number in the contact section.
3. Replace the temporary flyer/photo section with real C&C Landworks job photos after equipment is purchased.
4. Update any service or service-area wording you want changed.
5. Upload the folder to a GitHub repository and enable GitHub Pages.
6. Connect your purchased custom domain to GitHub Pages.

The site intentionally does not claim that customers must make an online appointment. Customers can request a quote online or call/text directly.
